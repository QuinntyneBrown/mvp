What Program.cs configures

  • JWT bearer authentication validating issuer, audience, lifetime, and signing key, with a 30-second clock skew.
  • CORS restricted to http://localhost:4200 with credentials allowed — an explicit origin, never a wildcard.
  • A global exception handler mapping validation failures to 400 with a { title, errors } body, authentication failures to 400 with a title, and everything else to a 500 that leaks nothing.

Persistence

AddInfrastructure switches on ConnectionStrings:Default:

ValueProvider
Empty, or InMemoryUseInMemoryDatabase — the shipped default
Anything elseUseSqlServer with that connection string
The default store is disposable

In-memory data does not survive a process restart. That is deliberate — it makes the first run work with nothing installed — but it is not a database. Migrations are not generated either; EntityFrameworkCore.Design is referenced so you can create them yourself.

Guarantees about the files

  • Deterministic. The same manifest produces byte-identical output.
  • UTF-8 without a byte-order mark, with LF line endings everywhere, regardless of the platform you generate on.
  • Contained. Every emitted path is relative and inside the target directory; a template that tried to escape is rejected.
  • Complete or absent. Files appear only after the whole tree renders successfully — see Output safety.
